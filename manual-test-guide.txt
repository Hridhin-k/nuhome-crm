NUHOME CRM — COMPLETE MANUAL TEST GUIDE
=======================================
For testers. Follow every numbered step in order inside each path.
Tick Expected after each step. Do not skip steps or paths.
Use a FRESH incognito window when switching people in the SAME browser,
unless the path says to keep two windows open (Realtime).


0. HOW TO USE THIS GUIDE
------------------------
Work in this order:

  PART 0   Setup, login, nav, role gates          (everyone)
  PATH A   Happy path — full pay end to end       (required first)
  PATH B   Reject quote + revise + advance + hold
  PATH C   Nil (credit) then later real payment
  PATH D   Installment while the job is with vendor
  PATH E   Cancel a dead quote / order
  PATH F   Split vendors, partial GRN, shortage, overdue
  PATH G   Payment rejected, then re-recorded
  PATH H   Customer GST / billing vs site / files
  PATH I   Tax invoice + installation + warranty / AMC
  PATH J   Public quotation + WhatsApp
  PATH K   Vendors, materials, company
  PATH L   Users, extra hats, cover, CSV, passwords
  PATH M   Lists, search, floor book, reports, audit
  PATH N   Each role's Home
  PATH O   Live refresh + every bell type
  PATH P   Negative / permission checks
  LOG      Pass / fail sheet at the end

If a step fails, stop that path, write the bug at the bottom
(quote number, role, step, expected vs actual), then continue the next path.

Status badges on screen (short). Cheat sheet at the end if you need the
internal name.

     Sales "Correct before send" on an Approved quote → new version → Pending.
     Old public link should not show the unapproved revision as sendable until
     Accounts approves again (and Sales sends).
